# Music Tutor AI - jazz band practice player

A practice player for Dax's jazz band guitar parts. Each song has three synced videos
with sliding sheet music, guitar tab, and counting:

- `<song>-full.mp4` - full practice band with guitar
- `<song>-guitar.mp4` - guitar only
- `<song>-minus.mp4` - band without guitar (you play)

Songs are listed in the `SONGS` config at the top of the script in `index.html`.

The backing band is a practice reconstruction made from the guitar part only,
not the official recording.
